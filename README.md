## About the Project

## Key Features

- **Single-Page Landing Architecture:** Fast, lightweight design with smooth navigation and zero external build dependencies.
- **Responsive Layout:** Adapts cleanly across desktop, tablet, and mobile screens.
- **Direct WhatsApp Integration:** Built-in contact links allowing clients to start project inquiries immediately.

## Running Locally

Because this is a pure static website, no build tools or package installations are required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/paradoverse/paradoverse.github.io.git
   ```

2. **Navigate into the project folder:**
   ```bash
   cd paradoverse.github.io
   ```

3. **Preview the site:**
   - Open `index.html` directly in any web browser, **or**
   - Use a local static server (such as the VS Code **Live Server** extension or Python's built-in server):
     ```bash
     python -m http.server 8000
     ```
     Then visit `http://localhost:8000`.

## Deployment & SEO

This site is automatically deployed through **GitHub Pages** from the repository's default branch.

- Any commits pushed to the main branch are published live at [https://paradoverse.github.io/](https://paradoverse.github.io/).
- Search indexing is managed via **Google Search Console** using the root `sitemap.xml` and verification meta tag inside `index.html`.
