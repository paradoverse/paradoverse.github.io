About the Project
Paradoverse is a single-page digital media agency website designed to showcase creative post-production and promotional services while giving prospective clients a fast, frictionless way to get in touch.
Live Website: https://paradoverse.github.io/
Services Highlighted
Video Editing: High-retention, polished edits tailored for digital platforms and brands.
VFX (Visual Effects): Seamless compositing and visual enhancements.
Motion Graphics: Custom animations, titles, and dynamic visual elements.
Campaign Promotion: Strategic content promotion to maximize reach and engagement.
Key Features
Single-Page Landing Architecture: Fast, lightweight design with smooth navigation and zero external build dependencies.
Responsive Layout: Adapts cleanly across desktop, tablet, and mobile screens.
Direct WhatsApp Integration: Built-in contact links allowing clients to start project inquiries immediately.
Search Engine Optimization (SEO): Configured with a custom favicon.png, sitemap.xml, robots.txt, and Google Search Console site verification for clean indexing.
Tech Stack
Frontend: HTML5, CSS3, JavaScript
Hosting: GitHub Pages
SEO & Analytics: Google Search Console, XML Sitemap, robots.txt
